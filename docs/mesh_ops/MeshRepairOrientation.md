# MeshRepairOrientation

`MeshRepairOrientation` クラスは、メッシュの三角形の向き（法線が内側と外側のどちらを向いているか）を修復します。

## 機能

このクラスは、2つの主要なステップで動作します。

1.  **`OrientComponents()`**:
    - メッシュを、エッジで接続された三角形の連結コンポーネントに分割します。
    - 各コンポーネント内で、すべての三角形が同じ方向を向くように、隣接する三角形の向きを揃えます。具体的には、共有エッジ `(a,b)` を持つ三角形がある場合、もう一方の三角形ではエッジが `(b,a)` となるように、必要であれば三角形を反転させます。
    - これにより、各コンポーネントは一貫した（ただし、グローバルに正しいとは限らない）向きを持つようになります。

2.  **`SolveGlobalOrientation()`**:
    - 各コンポーネントが、グローバルに「外側」と「内側」のどちらを向いているべきかを判断します。
    - この判断は、各三角形の法線方向に遠くからレイをキャストし、その三角形自身にヒットするかどうかをテストすることによって行われます。
        - **外向きの証拠 (`outFacing`)**: 法線と同じ方向（正の方向）からキャストしたレイがヒットした場合。
        - **内向きの証拠 (`inFacing`)**: 法線と逆の方向（負の方向）からキャストしたレイがヒットした場合。
    - 各コンポーネントについて、`inFacing` の面積の合計が `outFacing` よりも大きい場合、そのコンポーネント全体の三角形を反転させます。

## 使い方

```csharp
// 修復したいメッシュを取得
DMesh3 mesh = ...;

// MeshRepairOrientation のインスタンスを作成
MeshRepairOrientation orientRepair = new MeshRepairOrientation(mesh);

// --- ステップ 1: コンポーネント内の向きを揃える ---
orientRepair.OrientComponents();

// この時点で、各連結コンポーネントは一貫した向きになっていますが、
// 全体が内側を向いている可能性があります。


// --- ステップ 2: グローバルな向きを解決する ---
orientRepair.SolveGlobalOrientation();

// これで、メッシュ全体の向きが修復されているはずです。
// メッシュは直接更新されています。
```

## 注意点

- `SolveGlobalOrientation` は、レイキャスト法に依存するため、メッシュがほぼ閉じている場合に最も効果的に機能します。非常に開いたメッシュや複雑な自己交差を持つメッシュでは、期待通りに動作しない可能性があります。
- 処理は `DMeshAABBTree3` を内部で使用して高速化されます。
- `ComputeStatistics` は、`SolveGlobalOrientation` の内部で呼び出される統計計算部分です。個別に呼び出すこともできます。
