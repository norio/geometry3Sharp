# MinimalHoleFill

`MinimalHoleFill` クラスは、メッシュの穴を「最小」のサーフェスで埋めることを試みます。ここでの「最小」とは、面積だけでなく、曲率や三角形の品質も考慮したものです。この手法は、シャープなエッジを再構築したり、可展面（developable surface）に近い自然なフィルを生成するのに特に有効です。

## 機能

このクラスは、複数のパスからなる複雑なアルゴリズムを使用します。

1.  **初期フィル:** まず `SimpleHoleFiller` を使用して、穴を単純な三角形で埋めます。
2.  **サブメッシュ化:** フィルされた領域をサブメッシュとして抽出し、独立して操作できるようにします。
3.  **再メッシュ化:** フィル領域を `RemesherPro` で再メッシュ化し、後続の最適化パスのために適切な数の三角形を確保します。
4.  **第1段階（最小化）:**
    -   境界上の頂点を残しながら、内部のエッジを積極的に折りたたみ（collapse）、三角形の数を減らします。
    -   隣接する三角形の角度やエッジの長さを改善するために、エッジの反転（flip）を行います。
    -   これにより、大まかな最小メッシュを形成します。
5.  **第2段階（平坦化）:** エッジの反転を繰り返し、隣接する三角形ができるだけ平坦になるように（法線のドット積が1に近づくように）最適化します。
6.  **第3段階（曲率最適化）:** `OptimizeDevelopability` が `true` の場合、頂点でのガウス曲率がゼロに近づくようにエッジの反転を行います。これにより、シャープな折り目や平坦な領域が再構築されます。
7.  **第4段階（品質最適化）:** `OptimizeTriangles` が `true` の場合、三角形の形状（アスペクト比）を改善するためにエッジの反転を行います。ただし、これにより曲率が大きく悪化しない場合に限ります。
8.  **結果の反映:** 最適化されたサブメッシュを、元のメッシュに反映させます。

## 使い方

```csharp
// 穴を埋めたいメッシュと、その境界ループを取得
DMesh3 mesh = ...;
EdgeLoop boundaryLoop = ...;

// MinimalHoleFill のインスタンスを作成
MinimalHoleFill filler = new MinimalHoleFill(mesh, boundaryLoop);

// (オプション) パラメータを設定
filler.OptimizeDevelopability = true; // 曲率の最適化を有効にする (推奨)
filler.OptimizeTriangles = true;      // 三角形の品質最適化を有効にする (推奨)
filler.DevelopabilityTolerance = 0.01; // 品質最適化時に許容する曲率の変化

// 穴埋め処理を実行
bool success = filler.Apply();

if (success) {
    // 穴埋めが成功しました
    // メッシュは直接更新されています

    // (オプション) フィルによって生成された三角形を取得
    int[] filledTriangles = filler.FillTriangles;
}
```

## 注意点

-   このアルゴリズムは、特に第1段階のエッジ折りたたみにおいて、処理順序に影響されやすく、常に完璧な結果が得られるとは限りません。
-   非常に複雑な境界形状や、自己交差に近い境界を持つ穴に対しては、うまく機能しない場合があります。
-   `IgnoreBoundaryTriangles` を `false`（デフォルト）にすると、穴の周囲のメッシュの曲率も考慮に入れるため、より自然なフィルが得られます。
